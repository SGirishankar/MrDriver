Desi Mini Truck - web hosting folder (static, no build step)

Netlify: drag this whole "web" folder onto app.netlify.com/drop  (or: netlify deploy --prod --dir web)
Vercel:  vercel deploy web --prod   (framework preset: Other, no build command, output directory: .)

Open the site URL; the game page is index.html. Three.js and React load from cdnjs, so the players need internet.
Credits for the 3D models are printed in the browser console and listed in assets/vehicles/vehicles.json and assets/animals/LICENSE.txt.
